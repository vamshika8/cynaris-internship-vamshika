## Overview

Created an interactive sales analytics dashboard using Looker Studio to visualise sales data and explore product performance.

## Dashboard Features

- Total sales scorecard
- Sales by product bar chart
- Sales trends over time
- Product sales share pie chart
- Sales data table
- Region filter and date range control

## Tools Used

- Looker Studio
- Google Sheets
- Sales dataset
