# Week 1 - Day 1 Work Log

## CIA Insight

### Question

What are the most common SQL mistakes junior data analysts make?

### Insight

The most common SQL mistakes junior data analysts make include:

- Forgetting to use `WHERE` correctly, which can return unwanted rows.
- Using `= NULL` instead of `IS NULL` to check for missing values.
- Using incorrect `AND` / `OR` conditions.
- Forgetting that `LIKE` is used for pattern matching.
- Using incorrect `JOIN` conditions, which can create duplicate or incorrect results.
- Not checking for duplicate records.
- Using `SELECT *` unnecessarily instead of selecting required columns.
- Not validating query results before using them for analysis.

### Key Takeaway

A junior data analyst should write clear SQL queries, understand filtering conditions, handle NULL values correctly, and always verify the results before using them for analysis.
